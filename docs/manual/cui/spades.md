# Spades (スペード) — CUIマニュアル

## 起動

```sh
go run ./cmd/trumpcards spades
go run ./cmd/trumpcards --lang en spades  # 英語モード
```

## ルール概要

- 4人プレイ（1人 + CPU×3）、52枚のトランプ
- **スペードが常にトランプ（切り札）**
- 各ラウンド開始時にビッド（0〜13）を宣言
- ビッド0 = ニル（高リスク・高リターン）
- 2♣を持つプレイヤーが最初のトリックをリード
- リードスートに従う（フォロースート）。スペードはブレイクされるまでリードできない
- トリックの勝者: スペード（トランプ）が出ていれば最高のスペード、なければリードスートの最高値

## スコアリング

- **ビッド成功**: ビッド×10 + オーバートリック（バッグ）
- **ビッド失敗**: -ビッド×10
- **ニル成功**: +100点
- **ニル失敗**: -100点
- **バッグペナルティ**: 累積10バッグごとに-100点
- **勝利条件**: 先に500点に到達
- **敗北条件**: -200点以下

## コマンド一覧

| コマンド | 説明 |
|---------|------|
| `b <n>` / `bid <n>` | ビッドを宣言（0=ニル, 1-13） |
| `p <idx>` / `play <idx>` | カードをプレイ（インデックス指定） |
| `n` / `next` | 次のトリックへ |
| `nr` / `nextround` | ラウンドをスコアリングして次のラウンドへ |
| `sd <0-2>` / `setdifficulty <0-2>` | CPU難易度設定（0=Easy, 1=Normal, 2=Hard） |
| `sl <n>` / `setlimit <n>` | ポイント上限設定 |
| `log` / `l` | 棋譜表示 |
| `r` / `reset` | ゲームリセット（設定保持） |
| `q` / `quit` | ゲーム終了 |
| `help` / `?` | ヘルプ表示 |

## ゲームフロー

1. **ビッドフェーズ**: 各プレイヤーが獲得予想トリック数を宣言
2. **プレイフェーズ**: 13トリックを順番にプレイ
3. **トリック終了**: `next` で次のトリックへ
4. **ラウンド終了**: `nextround` でスコアリング → 次のラウンドへ
5. **ゲーム終了**: 勝利条件 or 敗北条件を満たしたら終了
