# Crazy Eights (クレイジーエイト) — CUIマニュアル

## 起動

```sh
go run ./cmd/trumpcards crazyeights
go run ./cmd/trumpcards --lang en crazyeights  # 英語モード
```

## ルール概要

- 4人プレイ（1人 + CPU×3）、52枚のトランプ
- 各プレイヤーに5枚ずつ配り、1枚を表向きにして捨て札の山を開始、残りは山札
- 捨て札の山のトップカードとスートまたはランクが一致するカードを出す
- **8はワイルド**: 出すと次のスートを選べる
- 出せるカードがなければ山札から1枚ドロー。出せればそのまま続行、出せなければパス
- 山札が空になったら捨て札（トップを除く）をリサイクルして山札にする
- ラウンド終了: 誰かが手札を全て出し切ったら終了
- スコアリング: 8=50点、J/Q/K=10点、A=1点、その他=額面
- ポイント上限（デフォルト200点）に達したプレイヤーが出たらマッチ終了

## コマンド一覧

| コマンド | 説明 |
|---------|------|
| `p <idx>` / `play <idx>` | カードをプレイ（インデックス指定） |
| `d` / `draw` | 山札から1枚ドロー |
| `s <1-4>` / `suit <1-4>` | スート選択（8を出した後）: 1=♠, 2=♣, 3=♥, 4=♦ |
| `nr` / `nextround` | ラウンドをスコアリングして次のラウンドへ |
| `sd <0-2>` / `setdifficulty <0-2>` | CPU難易度設定（0=Easy, 1=Normal, 2=Hard） |
| `sl <n>` / `setlimit <n>` | ポイント上限設定 |
| `l` / `log` | 棋譜表示 |
| `r` / `reset` | ゲームリセット（設定保持） |
| `q` / `quit` | ゲーム終了 |
| `help` / `?` | ヘルプ表示 |

## ゲームフロー

1. **プレイフェーズ**: スートまたはランクが一致するカードを出す、または山札からドロー
2. **スート選択**: 8を出した場合、次のスートを選択
3. **ラウンド終了**: 誰かが手札を全て出し切ったらスコア計算
4. **次のラウンド**: `nextround` で次のラウンドへ
5. **マッチ終了**: ポイント上限に達したプレイヤーが出たら終了
