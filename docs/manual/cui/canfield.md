# キャンフィールド（CUI版）遊び方

## ゲーム概要

キャンフィールド（Canfield）は1人用ソリティア。13枚のリザーブ、4列のタブロー、ファンデーションを使い、ベースランクから始めてすべてのカードを積み上げることを目指す。

## 起動方法

```sh
go run ./cmd/trumpcards canfield
go run ./cmd/trumpcards --lang en canfield
```

## ルール

- タブロー: 赤黒交互、降順、ラップアラウンド（K→A→...）
- ファンデーション: 同スート、ベースランクから昇順にラップアラウンド
- 空のタブロー列はリザーブから自動補充
- ストックは3枚ずつウェイストへめくる。リサイクル可

## ゲームの流れ

```mermaid
flowchart TD
    A[ゲーム開始 - reset] --> B[初期配布 リザーブ13 タブロー4列 ファンデーション1枚]
    B --> C{操作選択}
    C -->|d| D[ストックから3枚引く]
    C -->|m ...| E[カード移動]
    C -->|h| F[ヒント表示]
    C -->|ac| G[自動完成]
    C -->|u| H[元に戻す]
    D --> I{勝利判定}
    E --> I
    G --> I
    I -->|4組完成| J[クリア]
    I -->|継続| C
    C -->|g| K[ギブアップ]
    J --> L[リセットで次ゲーム]
    K --> L
```

## コマンド一覧

| コマンド | 短縮形 | 説明 |
|----------|--------|------|
| `d` / `draw` | `d` | ストックから3枚引く |
| `m w t <col>` | — | ウェイストからタブロー列へ |
| `m w f` | — | ウェイストからファンデーションへ |
| `m r t <col>` | — | リザーブからタブロー列へ |
| `m r f` | — | リザーブからファンデーションへ |
| `m t <col> f` | — | タブローからファンデーションへ |
| `m t <col> <idx> t <col>` | — | タブロー間移動 |
| `g` / `giveup` | `g` | ギブアップ |
| `hint` | `h` | ヒント |
| `ac` / `autocomplete` | `ac` | 自動完成 |
| `u` / `undo` | `u` | 元に戻す |
| `log` | `l` | 棋譜表示 |
| `reset` | `r` | リセット |
| `quit` | `q` | 終了 |
| `help` | `?` | コマンド一覧を表示 |

## 画面の見方

```
==========
Canfield
==========
Foundations: [♠5] [♥-] [♦-] [♣-]
Reserve(12): [♣K]
Tableau:
  0: ♥Q ♠J
  1: ♦10
  2: ♣9
  3: ♥8
Stock(21) / Waste(3): ... [♠4]
```

- **Foundations**: 4つのファンデーション。ベースランクから昇順に積む
- **Reserve**: 残り枚数とトップ1枚。タブロー空列を自動補充
- **Tableau**: 4列。赤黒交互・降順で重ねる
- **Stock / Waste**: 山札の残り枚数とウェイストのトップカード
