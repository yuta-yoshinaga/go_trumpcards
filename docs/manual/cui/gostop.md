# ゴーストップ（CUI版）遊び方

## ゲーム概要

ゴーストップ（Go-Stop / 고스톱）は、こいこいと同じ**花札（48枚）**を使う韓国の 2 人用**合わせ（キャプチャ）ゲーム**です。手札の札と山札からめくった札で場の**同じ月（花）の札**を捕獲し、集めた札を**光・五鳥・띠・열・피**の 5 カテゴリで採点します。目標点に達したら「**ゴー（続行）**」か「**ストップ（確定）**」を選びます。目標点に先に到達したプレイヤーが勝ちです。

## 起動方法

```sh
go run ./cmd/trumpcards gostop
go run ./cmd/trumpcards --lang en gostop  # 英語モード
```

## ルール

### デッキと配布

- **デッキ**: 花札48枚（12か月 × 各4枚：光・タネ・短冊・カス）。
- **プレイヤー**: 2人（プレイヤー0 = あなた、プレイヤー1 = CPU）。
- **配布**: 各プレイヤーに **10枚**、場に **8枚**を表向きに置きます。

### 手番と捕獲

1. 手札から1枚を出し、場にある**同じ月**の札を捕獲します。同じ月の札が場に**2枚**あるときは、捕獲する場札のインデックスを指定します。
2. 続けて山札から1枚めくり、同じ月の札があれば捕獲します。
3. 一致しなければ場に残ります。

### 得点カテゴリ（韓国式）

- **光（gwang）**: 光札の枚数に応じた点。
- **五鳥（godori）**: 鳥札3枚で5点。
- **띠（tti）**: 短冊5枚で1点、超過1枚ごと+1（赤短・青短・草短ボーナス）。
- **열（yeol）**: タネ5枚で1点、超過+1。
- **피（pi）**: カス10枚で1点、超過+1。

### ゴー / ストップ

- 目標点に到達するとゴー／ストップ決断になります。
  - **ゴー**: 続行。ゴー回数に応じて得点倍率が上がりますが、相手に逆転されると失点します。
  - **ストップ**: その時点の得点を確定します。
- 双方が目標点に届かず手札が尽きると引き分け（0点）です。

### バク（罰則）

- **光バク（gwang-bak）**: 敗者の光が0点なら支払い2倍。
- **ピバク（pi-bak）**: 敗者の피が規定枚数未満なら支払い2倍。
- **ゴーバク（go-bak）**: ゴー宣言側が逆転負けすると支払い2倍。

### 勝敗

- ラウンド得点を累計し、**目標点**（3 / 5 / 7 / 10）に先に到達したプレイヤーが勝ちです。

## コマンド一覧

| コマンド | 短縮形 | 説明 |
|----------|--------|------|
| `play <h> [f]` | `p` | 手札 h を出す。場札 f を指定（2枚一致時のみ必要） |
| `go` | `g` | ゴー（続行） |
| `stop` | `st` | ストップ（確定） |
| `nextround` | `n` | 次のラウンドを配る |
| `hint` | `h` | ヒントを表示 |
| `reset` | `r` | ゲームをリセット |
| `quit` | `q` | 終了 |
| `help` | `?` | コマンド一覧を表示 |
