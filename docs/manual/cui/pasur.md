# パスール（CUI版）遊び方

## ゲーム概要

イランで広く遊ばれている**フィッシング系**のカードゲーム。**手札1枚と場の数札の合計が11**になる組み合わせを取ります。**J・Q・Kは合計に使わず、場の同ランク札だけ**を取れます。取った結果**場が空になると「スール」**で、その捕獲の札は得点が2倍。山札を配り切った時点で得点の高い人の勝ちです。2〜4人で遊べます。

## 起動方法

```sh
go run ./cmd/trumpcards pasur
go run ./cmd/trumpcards --lang en pasur  # 英語モード
```

## ルール

### 配り

**まず場に4枚**置き、そのあと全員に**4枚ずつ**配ります。**場の4枚を先に引くのがポイント**で、残った48枚は2人・3人・4人のどれでも4枚ずつで割り切れます（それぞれ6・4・3パック）。全員の手札が尽きるたびに配り足し、山札が尽きたら終了です。

### 捕獲（合計11）

出した数札と、場の数札の合計が**ちょうど11**になる組み合わせを取ります。

| 札 | 値 |
|----|----|
| A | 1 |
| 2〜10 | その数 |
| J・Q・K | **合計に使わない** |

**手札1枚だけでは絶対に取れません。** 11ちょうどの札が無いので、どの捕獲にも必ず場の札が要ります。

### 絵札（J・Q・K）

絵札は**場の同ランクの札だけ**を取れます（合計には一切使いません）。同ランクが場に無ければ取れず、場に置くことになります。

### 取れるときは必ず取る

取れる組み合わせがあるときは、**場に置くことはできません**。置けてしまうと、点になる札を場へ流して相手に取らせない戦術が成立してしまいます。

### スール（場を空にする）

取った結果**場が1枚も残らなかったら「スール」**です。**その捕獲で取った札は得点が2倍**になります。

### 残り札

ゲーム終了時に場に残った札は、**最後に捕獲した人**のものになります。

### 得点

| 対象 | 点 |
|------|----|
| クラブ（♣）1枚につき | 1 |
| 2♣ | さらに +1（合計2点） |
| 10♦ | 3 |
| A 1枚につき | 1 |

**スールを除けば、1デッキから出る点はちょうど21点**です（クラブ13 + 2♣の上乗せ1 + 10♦の3 + エース4）。

## ゲームの流れ

```mermaid
flowchart TD
    A[ゲーム開始 - reset] --> B[場に4枚置く]
    B --> C[全員に4枚ずつ配る]
    C --> D[play で手札を1枚出す]
    D --> E{合計11の組み合わせがある?}
    E -- はい --> F[必ず取る - 場に置けない]
    E -- いいえ --> G[場に置く - トレール]
    F --> H{場が空になった?}
    H -- はい --> I[スール - その捕獲は得点2倍]
- 手番の案内には `場は N 枚。この N 枚を一度に取り切るとスール` と出るので、倍化を狙うかどうかをその場で判断できます。ヒントが勧める取り方が場を空にする場合は `← スール（2倍）` が付きます
    H -- いいえ --> J[通常の捕獲]
    I --> K{全員の手札が尽きた?}
    J --> K
    G --> K
    K -- いいえ --> D
    K -- はい --> L{山札が残っている?}
    L -- はい --> C
    L -- いいえ --> M[場の残り札は最後に捕獲した人へ]
    M --> N[得点計算 - 得点の高い人の勝ち]
```

## コマンド一覧

| コマンド | 短縮形 | 説明 |
|----------|--------|------|
| `play <i> [t...]` | `p` | 手札の `<i>` 番目を出す。`t...` は取る場札の番号（**省略すると場に置く**） |
| `hint` | `h` | 出すべき札と取り方を提示する |
| `giveup` | `g` | 投了する |
| `log` | `l` | 棋譜（アクションログ）を表示する |
| `reset` | `r` | 最初からやり直す |
| `quit` | `q` | 終了する |
| `help` | `?` | コマンド一覧を表示 |

**`t...` の省略は引数不足ではなく「場に置く」という指定です。** ただし取れる組み合わせがあるときは弾かれます。

## 画面の見方

```
==========
Pasur (パスール)
==========
配布: 1 パック目  山札: 残り32枚
手札1枚と場の数札の合計が11になる組み合わせを取ります。A=1〜10=10で、J・Q・Kは合計に使わず、場の同ランク札だけを取れます。取れる組み合わせがあるときは必ず取ります（場に置けません）。取った結果、場が空になると「スール」で、その捕獲の札は得点が2倍になります。
場: [0]♠7 [1]♥4 [2]♣3 [3]♦K
>あなた: 捕獲0枚 スール0 得点0 手札4枚
  [0]♦4 [1]♠K [2]♥9 [3]♣6
 CPU1: 捕獲0枚 スール0 得点0 手札4枚
 CPU2: 捕獲0枚 スール0 得点0 手札4枚
 CPU3: 捕獲0枚 スール0 得点0 手札4枚
----------
手番: あなた
play <i> [t...]・・・手札 i を出す（t... は場札の番号）
```

- **場の行**: `[0]` `[1]` … の番号が、そのまま `play <i> <t...>` の `t` です。この例なら `p 0 0`（♦4 で ♠7 を取る）か `p 0 1 2`（♦4 で ♥4+♣3 を取る）
- **捕獲**: 取った総枚数。得点そのものではありません
- **スール**: 場を空にした回数。**その捕獲の札だけが2倍**になります
- **得点**: 現時点の点数。クラブ・2♣・10♦・エースが対象です
- **`[最後に捕獲]`**: 終了時に**場の残り札を受け取る**席

## 遊び方のコツ

- **クラブを数える。** 13枚あるクラブが得点の主軸で、1枚1点。長い目で見ればここで差が付きます
- **2♣ と 10♦ は別格。** 2♣ は2点、10♦ は3点。この2枚は取れるときに取ります
- **場に絵札を置かない。** 絵札は同ランクでしか取れないので、置くと長く残り、スールが遠のきます
- **スールは倍。** 場が1〜2枚のときは、取れば空にできないか必ず確認します。2♣ を含むスールは4点になります
- **終盤は最後の捕獲を狙う。** 場の残りは最後に取った人のものです。終わりが近いなら、点札が場にあるときに取っておくと丸ごと入ります
- **取れるときは取るしかない。** 点にならない札で取らされる場面もあるので、手札の並びは先に読んでおきます
