# フラワーガーデン（CUI版）遊び方

## ゲーム概要

1人用のソリティアカードゲームです。1デッキ（52枚）を使用し、開始時にすべてのカードを表向きで配ります。6枚ずつの6つのオープンな「フラワーベッド（花壇）」（計36枚）に加え、**「ブーケ（花束）」と呼ばれる16枚のリザーブ**が1枚ずつ表向きで並びます。組札（ファンデーション）は最初は空です。ブーケのカードはフラワーベッドや組札へ出せますが、**一度出すと二度とブーケには戻せません（一方通行）**。4つの組札へA→Kの順にすべて積み上げきればクリアです。

## 起動方法

```sh
go run ./cmd/trumpcards flowergarden
go run ./cmd/trumpcards --lang en flowergarden  # 英語モード
```

## ルール

### 基本ルール

- 1デッキ（52枚、ジョーカーなし）を使用
- **組札（ファンデーション）は開始時は空**（プレイヤー自身がAを組札へ動かす）
- 36枚を6つのフラワーベッドへ表向きで配る（各ベッド6枚＝計36枚）
- 残りの16枚をブーケ（リザーブ）へ1枚ずつ表向きで配る
- 4つの組札（ファンデーション）はスート別にA→Kの順に積み上げる
- フラワーベッドでは**スートを問わず**、ランクが1つ下のカードに重ねる（例: ♠6の上に♥5・♦5・♣5・♠5のいずれでも可）
- 移動できるのは1枚ずつのみ（複数枚の同時移動は不可）
- **空のベッドには任意のカードを置ける**
- **ブーケは一方通行**: ブーケのカードはフラワーベッドや組札へ出せるが、ブーケへは何も戻せない

### ゲームクリア

- 4つの組札すべてにA→Kまで13枚ずつ積み上げるとゲームクリア

### ゲームオーバー

- これ以上移動可能な手がない場合は手詰まり（アンドゥやオートコンプリートで打開可能）

## ゲームの流れ

```mermaid
flowchart TD
    A[ゲーム開始 - reset] --> B[36枚を6つのベッドに配り、残り16枚をブーケに配る]
    B --> C{移動可能な手がある?}
    C -->|はい| D{プレイヤーのアクション}
    D -->|move| F[カードを移動]
    D -->|hint| G[ヒントを表示]
    D -->|autocomplete| H[自動で組札に積み上げ]
    D -->|undo| U[直前の手を取り消し]
    F --> I{組札が完成?}
    G --> C
    H --> I
    U --> C
    I -->|いいえ| C
    I -->|はい| J[ゲームクリア]
    C -->|いいえ| K[手詰まり]
    K -->|undo| C
    K -->|giveup| L[ゲームオーバー]
    J -->|reset| A
    L -->|reset| A
```

## コマンド一覧

| コマンド | 短縮形 | 説明 |
|----------|--------|------|
| `reset` | `r` | 新しいゲームを開始 |
| `move` | `m` | カードを移動する（サブ引数で移動元・移動先を指定） |
| `undo` | `u` | 直前の操作を元に戻す |
| `giveup` | `g` | ギブアップしてゲームを終了 |
| `hint` | `h` | 次の一手のヒントを表示 |
| `autocomplete` | `ac` | 自動的に組札へ積み上げ可能なカードを移動 |
| `log` | `l` | アクションログ（棋譜）を表示 |
| `quit` | `q` | ゲーム終了 |
| `help` | `?` | コマンド一覧を表示 |

### コマンド例

- `m t0 t1` → ベッド0の最上段カードをベッド1へ移動
- `m t3 f` → ベッド3の最上段カードを組札（ファンデーション）へ移動
- `m r0 t1` → ブーケ0番のカードをベッド1へ移動
- `m r0 f` → ブーケ0番のカードを組札へ移動
- `u` → 直前の操作を元に戻す
- `h` → ヒントを表示
- `ac` → オートコンプリート

## 画面の見方

```
==========
Flower Garden (フラワーガーデン)
==========
foundation: [  ] | [  ] | [  ] | [  ]
reserve: ♦7 | ♣9 | ♥2 | [  ] | ♠Q | ... (16枚)
----------
t0: [0]♠K [1]♥3 [2]♣8 [3]♦5 [4]♥10 [5]♠2
t1: [0]♣K [1]♥3 ...
...
t5: [0]♥J [1]♦9 [2]♥6 [3]♣4 [4]♠7 [5]♦Q
----------
moves: 0  undo:no
==========
```

- `foundation`: 4つのスート別の組札の状態（開始時は空）
- `reserve`: 16枚のブーケ（一方通行）。消化済みのセルは `[  ]` 表示
- `tN`: フラワーベッド（左がベース、右が最上段、各ベッド6枚）
- `[0]♠K`: ベッド内の位置インデックスとカード
- `moves: N`: 現在の手数

## 遊び方のコツ

- まずはベッドやブーケからAを探し出して組札へ上げ、続けてスート別の2を狙いましょう
- ブーケは戻せないので、空きベッドやスート無視の連結を活かして計画的に消化しましょう
- 空ベッドは任意のカードを置けるため、戦略的にベッドを空けると非常に強い手になります
- ヒント機能で詰まった時のアドバイスを得られます
- 手詰まりになったらアンドゥで戻ってリトライしましょう
