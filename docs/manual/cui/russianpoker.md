# ロシアンポーカー（CUI版）遊び方

## ゲーム概要

オアシスポーカーの発展形で、カード交換に加え6枚目のカード購入やディーラーカードの強制交換など、プレイヤーの判断機会が極めて多いカジノポーカーです。

## 起動方法

```sh
go run ./cmd/trumpcards russianpoker          # 日本語で起動
go run ./cmd/trumpcards --lang en russianpoker # 英語で起動
```

## ルール

- 52 枚のトランプ（ジョーカーなし）を使用
- プレイヤーとディーラーにそれぞれ 5 枚ずつ配る（ディーラーは 1 枚だけ表向き）
- プレイヤーは「コール」「フォールド」「カード交換」「6枚目購入」から選択
- 交換手数料はアンテ × 交換枚数、6枚目購入手数料はアンテ同額
- ディーラーは「A と K を含む」または「ペア以上」でクオリファイ
- ディーラー未クオリファイ時、アンテ同額を払ってディーラーの最高カードを交換させることができる

## ゲームの流れ

```mermaid
flowchart TD
    A[開始] --> B["b &lt;ante&gt; でベット"]
    B --> C{"p/e/6/f で選択"}
    C -->|"p (コール)"| D{ディーラークオリファイ?}
    C -->|"f (フォールド)"| E[アンテ＋手数料没収]
    C -->|"e idx... (交換)"| F["p/f で選択"]
    C -->|"6 (6枚目購入)"| G["sel idx で1枚捨てる"]
    G --> F
    F -->|"p (コール)"| D
    F -->|"f (フォールド)"| E
    D -->|はい| H[勝敗判定]
    D -->|いいえ| I["force/d で選択"]
    I -->|"force (交換させる)"| J[再判定]
    I -->|"d (辞退)"| K[アンテ1対1返却]
    H --> L[END]
    J --> L
    K --> L
    E --> L
    L -->|"r (リセット)"| B
```

## コマンド一覧

| コマンド | 説明 |
|----------|------|
| `b <ante>` | アンテをベット |
| `e <idx ...>` | 指定インデックス（0〜4）のカードを交換 |
| `6` | 6枚目のカードを購入（手数料 = アンテ） |
| `sel <idx>` | 6枚の手札から指定インデックス（0〜5）を捨てる |
| `p` | コール（プレイベット = アンテ × 2） |
| `f` | フォールド |
| `force` | ディーラーの最高カードを交換させる（手数料 = アンテ） |
| `d` | 強制クオリファイを辞退 |
| `log` | 棋譜を表示 |
| `r` | リセット |
| `q` | 終了 |

## 画面の見方

```
----------
チップ: 1000
フェーズ: ACTION
--- PLAYER ---
♠A,♥K,♦Q,♣J,♠10
--- DEALER ---
♥7,??,??,??,??
----------
```

- `??` はディーラーの伏せカード
- フェーズ名で現在の操作が分かる

## 遊び方のコツ

- ペア以上ならコールが基本。A-K ハイもコール推奨
- フラッシュ/ストレートにあと 1 枚の時は 6 枚目購入が有効
- 強い手（フルハウス以上）で未クオリファイの場合は `force` で配当倍率を狙う
- 交換は 1〜2 枚が費用対効果が良い
