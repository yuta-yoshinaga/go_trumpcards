# Gin Rummy (ジンラミー) — CUIマニュアル

## 起動

```sh
go run ./cmd/trumpcards ginrummy
go run ./cmd/trumpcards --lang en ginrummy  # 英語モード
```

## ルール概要

- 2人プレイ（1人 + CPU×1）、52枚のトランプ
- 各プレイヤーに10枚ずつ配り、1枚を表向きにして捨て札の山を開始、残りは山札（ストック）
- 手番ではまず山札または捨て札の山からカードを1枚ドローする
- その後、手札からカードを1枚捨てるか、ノックする
- **メルド**: セット（同ランク3〜4枚）またはラン（同スート3枚以上の連番）
- **デッドウッド**: メルドに含まれない手札の合計点（J/Q/K=10点、A=1点、その他=額面）
- **ノック**: デッドウッド合計が10以下の時にノック可能。相手はノッカーのメルドにレイオフ（カードを付け足す）できる
- **ジン**: デッドウッド0でノック。25点ボーナス。相手はレイオフ不可
- **アンダーカット**: 相手のデッドウッドがノッカー以下の場合、相手に25点ボーナス
- ポイント上限（デフォルト100点）に達したプレイヤーが出たらマッチ終了

## コマンド一覧

| コマンド | 説明 |
|---------|------|
| `ds` / `drawstock` | 山札から1枚ドロー |
| `dd` / `drawdiscard` | 捨て札の山から1枚ドロー |
| `d <idx>` / `discard <idx>` | カードを捨てる（インデックス指定） |
| `k` / `knock` | ノック（デッドウッド≤10の時） |
| `lo <idx...>` / `layoff <idx...>` | レイオフ（相手のノック後、メルドにカードを付け足す） |
| `nr` / `nextround` | ラウンドをスコアリングして次のラウンドへ |
| `sd <0-2>` / `setdifficulty <0-2>` | CPU難易度設定（0=Easy, 1=Normal, 2=Hard） |
| `sl <n>` / `setlimit <n>` | ポイント上限設定 |
| `l` / `log` | 棋譜表示 |
| `r` / `reset` | ゲームリセット（設定保持） |
| `q` / `quit` | ゲーム終了 |
| `help` / `?` | ヘルプ表示 |

## ゲームフロー

1. **ドローフェーズ**: 山札または捨て札の山から1枚ドロー
2. **ディスカード/ノックフェーズ**: カードを1枚捨てるか、ノックする
3. **レイオフフェーズ**: ノック後（ジンでない場合）、相手がメルドにカードを付け足す
4. **ラウンド終了**: スコア計算。`nextround` で次のラウンドへ
5. **マッチ終了**: ポイント上限に達したプレイヤーが出たら終了
