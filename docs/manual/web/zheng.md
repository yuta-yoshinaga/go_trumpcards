# 争上游（Web版）遊び方

## ゲーム概要

Zheng Shangyou (争上游 / ジェンシャンヨウ) は、中国の伝統的なクライミング（手札消化）ゲームで、大富豪やビッグツーの祖先にあたります。あなたは**席0**としてCPU3人と対戦し、手札を最も早く出し切ることを目指します。ジョーカー2枚を含む54枚デッキを使い、**スートはカードの強さに一切関係しない**のが特徴です。

## 起動方法

```sh
go run ./cmd/trumpcards web         # CLI経由でWebサーバーを起動
go run ./cmd/trumpcards web --open  # サーバー起動 + ブラウザを開く
go run ./cmd/server                 # 直接Webサーバーを起動
```

ブラウザで `http://localhost:8080` にアクセスし、ナビゲーションバーから「争上游」を選択します。
ナビバーのJA/ENボタンで日本語・英語を切り替えられます。

## ルール

### デッキと配布

- **デッキ**: 54枚（52枚 + 小ジョーカー・大ジョーカー）。
- **プレイヤー**: 4人（あなた = 席0、CPU1〜3）。順番に配り切るため、席0・1が14枚、席2・3が13枚になります（この不均等は仕様です）。

### カードの強さ

`3 < 4 < ... < K < A < 2 < 小ジョーカー < 大ジョーカー`

**スートは無関係**です。同ランクのカードはスートが違っても互角で、場のカードを超えられません。

### 役（コンビネーション）

- **シングル**: 1枚。
- **ペア**: 同ランク2枚（ジョーカー同士はランクが異なるためペア不可）。
- **スリーカード**: 同ランク3枚。
- **ストレート**: 3枚以上の連続ランク。**3〜Aのみ**（2とジョーカーは使えません）。
- **連続ペア**: 3組以上の連続するペア（例: 44-55-66）。同じく3〜Aのみ。

### 爆弾

- **フォーカード（爆弾）**: 同ランク4枚。任意の通常役をタイプ・枚数無視で切れます。爆弾同士はランク比較です。
- **ジョーカーボム**: ジョーカー2枚。爆弾を含む**全てに勝つ**最強役です。

爆弾・ジョーカーボムはリードでも出せます。

### 進行

- **先攻**: ♠3 を持つプレイヤー。先攻は必ず何かを出します。
- **出し方**: 場と同じ役・同じ枚数で、より高いキーランク（役中の最高ランク）を出すかパス。
- **場のリセット**: 他全員がパスすると場がクリアされ、最後に出したプレイヤーが自由にリードします（上がっている場合は次のアクティブプレイヤーへ）。
- **勝敗**: 出し切った順に1位〜3位、最後まで残った1人が4位でゲーム終了です。

## 操作

- **カードを出す**: 手札のカードをクリックして選択し、「出す」ボタンを押します。
- **パス**: 場にカードがあるときは「パス」ボタンでパスできます（リード時はパス不可）。
- **リセット**: 「リセット」ボタンで新しいゲームを開始します。
- **CPU難易度**: 設定から Normal / Easy / Hard を選べます（変更するとゲームがリセットされます）。
- **CLIモード**: 画面右上のトグルでコマンド入力モードに切り替えられます。

## 遊び方のコツ

- 弱いカードから順に出し、2やジョーカーは温存しましょう。
- スートは無関係なので、同ランクでは場を超えられません。1ランクでも高いカードが必要です。
- フォーカードとジョーカー2枚は切り札です。相手の強い出しに合わせて使いましょう。
- 相手の残り枚数に注意し、上がり間際の相手には強い役や爆弾で蓋をしましょう。
