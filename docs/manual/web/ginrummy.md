# Gin Rummy (ジンラミー) — Web GUIマニュアル

## アクセス

```sh
go run ./cmd/trumpcards web
# ブラウザで http://localhost:8080/#/ginrummy を開く
```

## ルール概要

- 2人プレイ（1人 + CPU×1）、52枚のトランプ
- 各プレイヤーに10枚ずつ配り、1枚を表向きにして捨て札の山を開始、残りは山札（ストック）
- 手番ではまず山札または捨て札の山からカードを1枚ドローする
- その後、手札からカードを1枚捨てるか、ノックする
- **メルド**: セット（同ランク3〜4枚）またはラン（同スート3枚以上の連番）
- **デッドウッド**: メルドに含まれない手札の合計点
- **ノック**: デッドウッド合計が10以下の時にノック可能
- **ジン**: デッドウッド0でノック。25点ボーナス。相手はレイオフ不可
- **アンダーカット**: 相手のデッドウッドがノッカー以下の場合、相手に25点ボーナス
- ポイント上限に達したらマッチ終了

## Web GUI操作

### ドローフェーズ
- 「山札からドロー」ボタンでストックから1枚引く
- 「捨て札からドロー」ボタンで捨て札の山のトップカードを引く

### ディスカード/ノックフェーズ
- 手札のカードをクリックして選択（1枚）
- 「捨てる」ボタンで選択したカードを捨てる
- 「ノック」ボタンでノック（デッドウッド≤10の場合のみ有効）

### レイオフフェーズ
- 相手がノックした場合（ジンでない場合）、ノッカーのメルドにカードを付け足せる
- 手札のカードをクリックして選択し、「レイオフ」ボタンで付け足す

### ラウンド終了
- 「次のラウンド」ボタンで進行

### 設定パネル
- **CPU難易度**: Easy / Normal / Hard
- **ポイント上限**: デフォルト100

### スコアテーブル
- 各プレイヤーのラウンドスコアと累積スコアを表示
