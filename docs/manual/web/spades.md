# Spades (スペード) — Web GUIマニュアル

## アクセス

```sh
go run ./cmd/trumpcards web
# ブラウザで http://localhost:8080/#/spades を開く
```

## ルール概要

- 4人プレイ（1人 + CPU×3）、52枚のトランプ
- **スペードが常にトランプ（切り札）**
- 各ラウンド開始時にビッド（0〜13）を宣言
- ビッド0 = ニル（成功+100点, 失敗-100点）
- 2♣を持つプレイヤーが最初のトリックをリード
- リードスートに従う。スペードはブレイクされるまでリードできない

## スコアリング

- ビッド成功: ビッド×10 + オーバートリック（バッグ）
- ビッド失敗: -ビッド×10
- 累積10バッグごとに-100点ペナルティ
- 先に500点で勝利、-200点以下で敗北

## Web GUI操作

### ビッドフェーズ
- 数値入力欄にビッド数（0〜13）を入力
- 「ビッド」ボタンで確定
- 0 = ニルビッド

### プレイフェーズ
- 手札のカードをクリックして選択（1枚）
- 「カードを出す」ボタンでプレイ

### トリック/ラウンド終了
- 「次のトリック」「次のラウンド」ボタンで進行

### 設定パネル
- **CPU難易度**: Easy / Normal / Hard
- **目標スコア**: 200 / 300 / 500 / 750 / 1000

### スコアテーブル
- 各プレイヤーのビッド、獲得トリック数、バッグ数、ラウンドスコア、累積スコアを表示

## API

```
POST /spades/exec
```
