# Durak (ドゥラーク)

## ゲーム概要

Durak（ドゥラーク）は東欧で人気のカードゲームです。36枚のデッキ（各スートの6〜A）を使用し、2〜6人でプレイします。最後まで手札を持っているプレイヤーが「ドゥラーク（愚か者）」として負けとなります。

## 基本ルール

### デッキと配り
- 36枚デッキ（6, 7, 8, 9, 10, J, Q, K, A × 4スート）
- 各プレイヤーに6枚ずつ配る
- 山札の底のカードが切り札スートを決定

### ゲームの流れ

1. **攻撃フェーズ**: 攻撃者がカードを1枚出す
2. **防御フェーズ**: 防御者がより強いカードで防ぐ
3. **バウト終了**: 防御成功ならカードは捨て札、失敗なら防御者が全て引き取る
4. 山札から手札が6枚になるよう補充

### カードの強さ
- 同スート内: 数値が大きいほど強い（6 < 7 < ... < K < A）
- 切り札スートのカードは非切り札の全てに勝つ
- 異スート（切り札でない）同士では防御不可

## 操作方法

| ボタン | 説明 |
|--------|------|
| 攻撃 | 選択したカードで攻撃する |
| 防御 | テーブルの攻撃カードを選択し、手札のカードで防御する |
| パス | 追加攻撃をやめる（攻撃フェーズ中のみ） |
| 引き取り | テーブルのカードを全て引き取る（防御放棄） |

## 勝利条件

手札を先になくしたプレイヤーから順に上がり。最後まで手札を持っていたプレイヤーが「ドゥラーク」（負け）です。
